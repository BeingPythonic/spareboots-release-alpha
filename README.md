# Tamble — alpha test builds

Development builds of **Tamble** by Paper Arcane Studios Inc., for invited alpha testers.

**To play:**
1. Download **TambleSetup.exe** from the [`installer` release](../../releases/tag/installer).
2. Run it.
3. Start Tamble from the Start menu.

The launcher keeps itself and the game up to date. Steam must be running and logged in.

This repository holds only release files, published automatically. There is no source code here.
